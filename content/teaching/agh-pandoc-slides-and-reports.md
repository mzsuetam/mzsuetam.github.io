# AGH Themed Pandoc Slides and Reports

Here i would like to share Pandoc themes for Beamer slides and reports that I have created to make writing both lab/project reports and presentation slides easier and consistent.

Both themes are based on LaTeX (and Beamer for slides) and can be used with Pandoc to generate PDF documents directly from Markdown files.

### What is Pandoc and why use it?

Pandoc is a universal document converter that allows you to convert files from one markup format to another. It supports a wide range of formats including Markdown, LaTeX, HTML, and more.

One of the main advantages of using Pandoc is its ability to separate content from presentation. This means you can focus on writing your content in a simple and readable format (like **Markdown**) while Pandoc takes care of formatting it according to the specified theme.

Writing in Markdown is often **faster and more efficient** than writing directly in LaTeX, especially for those who are not familiar with LaTeX syntax. What is more, one can write the presentation slides and reports **in the same repo** as the full project in the `docs/` folder (so **all project documentation is in one place**) and, what is most important, there is **no need to use Microsoft Word or PowerPoint** :) or Overleaf.

> To use these themes, you must have Pandoc and additional libraries installed. Check the requirements section in each GitHub repository for details.
