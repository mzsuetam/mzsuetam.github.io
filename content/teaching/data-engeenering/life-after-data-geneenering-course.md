First of all, congratulations on completing the Data Engineering course! 🎉

## Data Engineering/Science Recaps

- **McKinney W. - *Python for Data Analysis*** – Basics of working with data in Python using Pandas and NumPy. A great book for learning data manipulation, analysis, and visualization, especially to get familiar with practical examples.
- **Nield T. - *Essential Math for Data Science*** – An accessible introduction to the math behind data science: calculus, probability, linear algebra, statistics, and their applications in regression and neural networks. After math courses in ISI, this is a very good review and supplement.

Exploratory Data Analysis (EDA) is a crucial step in any data project. 
As this is a broad topic, I link [the Wikipedia article on EDA](https://en.wikipedia.org/wiki/Exploratory_data_analysis) as a starting point. You can find a list of techniques and methods used in EDA there.

## Advanced Data Engineering Topics

* **Kleppmann M. - *Designing Data-Intensive Applications*** – A classic on distributed systems and databases, often called the "Bible" of the industry. It covers the foundational theory: replication, consistency, the CAP theorem, and fault-tolerant systems. While more advanced, it is the gold standard for understanding *how* the tools we use actually work under the hood. If you want to pass a Senior DE interview, this is the book.
* **Reis J., Housley M. - *Fundamentals of Data Engineering*** – If Kleppmann is the "Deep Theory," this is the "Modern Reality." It provides a high-level framework called the Data Engineering Lifecycle, focusing on how to evaluate tools and architect systems rather than just writing code. It covers essential professional topics like cost optimization, data security, and the transition from Data Lakes to Lakehouses. It is widely considered the definitive roadmap for the modern data professional.
